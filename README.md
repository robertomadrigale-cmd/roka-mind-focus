# ROKA MIND FOCUS

Aplicacion PWA de enfoque, mentalidad, estrategia, reflexion y base personal.

## Produccion

https://roka-zen-full.web.app

## Desarrollo local

```bash
python -m http.server 4173
```

Luego abre:

```text
http://127.0.0.1:4173
```

## Deploy

```bash
firebase deploy --only hosting
```

El proyecto Firebase configurado es `roka-zen-full`.
