Política de Privacidad

Última actualización: 23 de septiembre de 2026

ROKA MIND FOCUS guarda información personal para ayudarte a planear, revisar progreso y usar funciones de Coach e informes con IA. Esta política explica qué datos se procesan, dónde se guardan y cuándo se comparten con proveedores externos.

1. Información que recopilamos

  • Cuenta: al iniciar sesión con Google/Firebase se procesa tu identificador de usuario, nombre, correo y foto de perfil.
  • Datos de la app: metas SMART, tareas, rituales, rueda de vida, creencias, mantras, gratitud, orgullos, reflexiones, mapa personal, preferencias y configuración.
  • Datos sensibles que tú decides escribir: historia de vida, miedos, valores, fecha/hora/lugar de nacimiento, eneagrama y notas personales.

2. Almacenamiento y sincronización

Los datos se guardan en tu navegador para funcionamiento offline y se sincronizan con Firebase Firestore cuando inicias sesión. El estado local queda marcado por cuenta para evitar que otro usuario del mismo navegador reciba datos anteriores.

3. Uso de IA y transferencia a terceros

Cuando usas el Coach, rutas o informes, ROKA puede enviar a proveedores de IA el texto de tu conversación, el prompt solicitado y el contexto que autorices con los interruptores de la app. Si activas contexto sensible, también pueden enviarse miedos, historia personal y datos de nacimiento.

  • OpenAI: se usa mediante el gateway del servidor cuando está configurado.
  • Google Gemini: puede usarse por gateway o llamada directa desde tu navegador si aportas tu API key.
  • DeepSeek: puede usarse por gateway o llamada directa desde tu navegador si aportas tu API key. DeepSeek puede procesar datos fuera de México.

La API key de IA la aporta el usuario. Por defecto se guarda solo en sessionStorage; solo se conserva en localStorage si marcas "Recordar en este dispositivo". No se guarda en Firestore.

4. Cómo desactivar IA o reducir contexto

Puedes borrar la API key desde Perfil, elegir no recordar la llave, cambiar proveedor/modelo o desactivar los interruptores de contexto de metas/progreso e historia personal/bloqueos. Si no usas Coach ni informes, esos textos no se envían a proveedores de IA.

5. Cookies y almacenamiento local

La app usa almacenamiento local esencial para sesión, preferencias, progreso offline y caché de PWA. Actualmente no carga analytics.

6. Control de tus datos

Puedes editar o exportar datos desde la app. Para solicitar eliminación completa de datos en la nube, contacta al responsable del servicio.
